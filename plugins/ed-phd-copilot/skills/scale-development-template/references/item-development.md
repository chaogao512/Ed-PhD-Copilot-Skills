# Item Development for EdTech Governance Scales

## 1. Item pool construction

- Generate ≥2–3 items per dimension (3–5 preferred to survive EFA deletion); an initial pool of 1.5–2× the target final length is standard.
- Write items at the reading level of the target population; avoid double-barreled items ("学校提供了培训且经费充足"), leading wording, and negation traps.
- One item = one idea; use concrete behaviors rather than abstractions where possible ("我能在课堂上使用数据分析结果调整教学" beats "我具备数据素养").
- Balance positively and negatively worded items only when reverse scoring is planned and checked; avoid excessive negation.
- Specify the response format: Likert frequency/agreement scale (5- vs 7-point — justify), anchors defined at both ends, no midpoint unless designed.

## 2. Item review checklist

| Check | Question |
|---|---|
| Relevance | Does the item measure the intended dimension, not another? |
| Clarity | Would a respondent with no research background understand it? |
| Specificity | Does it name a concrete behavior, object or situation? |
| Social desirability | Would most respondents answer it the "good" way regardless of truth? |
| Cultural fit | Is the wording natural for Chinese education settings (avoid direct translation artifacts)? |
| Coverage | Do items jointly cover the dimension definition including its boundaries? |
| Distinctness | Does the item clearly belong to exactly one dimension? |

## 3. Expert review (content validity)

- Panel: 5–10 experts (field experts + measurement experts + practitioner representatives where relevant).
- Task: rate each item for relevance (4-point scale: 1 = not relevant ... 4 = highly relevant) and clarity; comment freely.
- Compute I-CVI per item (proportion of experts rating 3 or 4): ≥ 0.78 with ≥ 5 experts; S-CVI/Ave ≥ 0.90 target.
- Record revision decisions item by item: kept as-is / revised (what changed) / deleted (why).
- Add a second expert round if substantial revision occurred; report both rounds.

## 4. Pilot test

- Sample: small but adequate for item screening (commonly 30–100 for a first pilot; scale with the number of items — state the logic).
- Collect: item responses + cognitive probe feedback (which items were confusing, why).
- Item statistics to inspect: item mean/floor-ceiling effects (mean near extremes), item variance, item-total correlation (target ≥ 0.30–0.40), and, for multi-dimensional scales, item-dimension correlations.
- Decision rules: delete items with near-zero variance, negative or very low item-total correlations, or systematic confusion reports — record each decision.

## 5. Anti-patterns

- Writing items before the construct definition is complete.
- Skipping expert review "because the items came from prior literature" (adaptation still requires relevance judgment for the new population).
- Pilot-testing and validation-sampling from the same dataset without stating it.
- Translating an English scale item-for-item without cultural adaptation evidence.
- Hiding deleted items: report the full initial pool, the deletion decisions and the reasons.
