# 3.2 论文 Introduction 写作的思考模型（教育技术版）

> 本文改编自 [Supervisor-Skills](https://github.com/HKUSTDial/Supervisor-Skills) (CC BY-NC-SA 4.0)，内容已针对教育技术专业博士研究场景进行迁移适配。

> Introduction 是整个论文的精简版。

一般来说，Introduction 可以看作整篇论文的"压缩版"：用最少的篇幅把研究对象讲清楚，把问题为什么难讲透，再把我们的方法/研究设计为什么必要讲明白。

## Introduction 的写作组织

一个清晰的写作组织是：

1. **场景与背景**：先用一个典型教学场景/运行例子引出研究背景与需求
2. **现有工作与局限**：随后对现有代表性工作进行归纳，找其在理论假设、数据条件、应用场景约束与方法论局限下暴露的主要局限（通常不超过 3 点）
3. **问题刻画与目标**：在此基础上进一步刻画该问题的本质属性与硬约束（例如样本规模、情境动态性、学习者群体的异质性、实施成本、效度与信度要求等），从而自然导出本文要解决的研究目标或问题定义（Our Goal / Problem Formulation / Research Questions），或支撑方案设计的核心洞见（Key Idea）
4. **关键挑战**：接着，需要明确实现该目标所面临的关键挑战（通常不超过 3 点），解释为何直接套用或简单扩展已有方法难以奏效（教育研究中常见挑战：数据稀疏与异构、因果推断困难、技术方案与课堂节奏/组织制度的适配）
5. **方法总览**：最后给出与挑战一一对应的方法总览（整体框架与关键模块；实证研究可压缩为"干预 + 研究设计"一句话总览，细节放 Method 章节）
6. **贡献总结**：以贡献点收束，包括问题定义/设定（若有）、理论/框架设计、1-2 个关键技术亮点，以及充分的实证评估与分析（教育技术论文的贡献必须至少包含一项"对教与学意味着什么"）
