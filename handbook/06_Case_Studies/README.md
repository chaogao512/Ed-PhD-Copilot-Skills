# 第六章：论文写作剖析案例（教育技术版）

> **状态：建设中** — 本章目前仅有规划说明，暂无完整案例剖析。收录案例后，此处将逐篇补充 EdTech 代表性论文的逐段剖析。

> 本章为迁移新增章节（基于 [Supervisor-Skills](https://github.com/HKUSTDial/Supervisor-Skills) 第六章结构规划，CC BY-NC-SA 4.0）。原 Supervisor-Skills 中的三篇案例分析（Alpha-SQL / AFlow / LEAD，分别出自 ICML 2025 / ICLR 2025 / VLDB 2026）均为计算机科学领域的系统类论文，与教育技术领域的论文范式（理论锚定 + 实证证据链 + 教育实践启示）有根本差异，不纳入迁移范围。

## 待收录内容

本章将收录教育技术领域的代表性论文写作剖析案例，拟涵盖以下类型：

- **设计研究型论文**（如学习分析干预的迭代设计，可对标 ETR&D、BJET 的 DBR 论文）
- **实证研究型论文**（如教育技术干预的准实验/RCT 效果评估，可对标 C&E、JEP 的实证论文）
- **系统开发与评估型论文**（如智能导学系统的设计、实现与评估，可对标 IJAIED、AIED 的系统论文）
- **理论/框架型论文**（如教育 AI 治理框架、人机协同教学模型，可对标 ETR&D、Educational Psychology Review 的理论论文）
- **评估工具/量表开发型论文**（如学习投入量表、计算思维测量工具的开发与验证）

## 剖析方法

建议沿用第三章 3.2「Introduction 写作/构思的 Flowchart」的分析框架，对每篇案例做逐段映射检验：从研究背景出发，经过 Limitation 分析、研究问题定义、关键挑战，最终到方法/研究设计总览和贡献总结，验证逻辑闭环。

案例待后续根据作者实际发表经验补充。
