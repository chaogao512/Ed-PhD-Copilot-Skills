## What Improved

### 1. Discussion / limitations / implications writing (new skill: `governance-discussion-drafter`)

The previously missing capstone of the paper workflow now exists with four references: paragraph patterns (seven ordered discussion moves), a limitation taxonomy (sampling/measurement/design/analysis/validity threats, each tied to weakened claims and bias direction), implication mapping (finding-anchored theoretical/practical/policy implications with boundary conditions), and worked examples. Example output `docs/examples/08-governance-discussion-drafter-output.md` demonstrates the full skeleton.

### 2. Qualitative coding depth (`qualitative-coding-guide.md`)

Adds open/axial/selective coding workflow, Braun & Clarke six-phase thematic analysis, double-coding with Cohen's κ thresholds, a codebook template, COREQ-aligned reporting fields and software-agnostic audit-trail rules — upgrading qualitative evidence from "mention coding" to "reproducible coding".

### 3. Systematic review methodology (`systematic-review-workflow.md`)

Adds review-type selection, protocol stage, search/record stage, PRISMA-style screening flow, quality appraisal (MMAT / WWC / CASP / AMSTAR-2), synthesis options and gap-identification matrix, plus a reporting gate that refuses the "systematic review" label when the flow is not reproducible.

### 4. Statistics reporting standards (`quantitative-methods.md` extension)

Adds effect-size reporting (Cohen's d, η², β, OR, r/Cramer's V, R²/ΔR² with CIs), robustness-check guidance per design type, and power-analysis minimum requirements (MDE, realistic field effect sizes, EFA/CFA sample planning, moderation power caveats).

### 5. APA 7th / Chinese CSSCI format gates (`format-gates.md`)

Adds a format dimension for the pre-submission reviewer: APA 7th citation/reference/statistics/table/figure rules, GB/T 7714 and Chinese CSSCI conventions (顺序编码制, 三线表, 政策文件引用规范), a format audit procedure, and the rule that format checks run after, never instead of, content checks.

### 6. Standalone scale development skill (`scale-development-template`)

The previously embedded indicator/scale path is now a full skill: construct definition → item development → expert review (I-CVI/S-CVI) → pilot → EFA/CFA → reliability/validity evidence → norms/cut-offs, with a routing rule from `mixed-methods-evidence-template`. Example output `docs/examples/09-scale-development-template-output.md` demonstrates the pipeline.

### 7. Classic EdTech theory anchors (`theory-anchors.md` expansion)

Adds CoI, cognitive load theory, SDT, UTAUT, diffusion of innovations, institutional theory, sociomateriality/actor-network and learning-analytics ethics frameworks — each with design implications, evidence implications and failure signals.

### 8. Fourth transfer case: learning analytics governance

New case "基于学习分析的大学生学业预警与精准支持机制研究" runs the full seven-skill chain and stresses labeling, proxy-indicator misuse, student consent and appeal rights. New failure case 11 (`11-learning-analytics-labeling.md`) regression-tests the ethics gates.

## Remaining Gaps

### 1. Installed-skill trigger testing remains pending

The repository is ready for installation testing, but the active environment has not been modified because the user previously asked not to install until after adaptation.

### 2. Verified Chinese journal literature is still the largest evidence gap

The skill avoids fabricated Chinese citations, but mature V2.0 use still needs a small set of verified Chinese CSSCI/core-journal articles with exact metadata.

### 3. A doctoral proposal sample is not yet fully drafted

The templates and stages exist, but there is not yet a complete 开题报告-style sample using the user's actual research direction.

### 4. Research-design flow diagram is still missing

The rendered figure set covers mechanism diagrams, but not a dissertation research-design flow diagram showing how policy text, interviews, survey/log data and ethics evidence integrate.
