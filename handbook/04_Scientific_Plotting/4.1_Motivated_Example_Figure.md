# 4.1 Motivated Example Figure（动机示例图）（教育技术版）

> 本文改编自 [Supervisor-Skills](https://github.com/HKUSTDial/Supervisor-Skills) (CC BY-NC-SA 4.0)，内容已针对教育技术专业博士研究场景进行迁移适配。

## 论文绘图总论

在教育技术领域的 SSCI/CSSCI 期刊与顶会（如 LAK、AIED、EDM 等）论文中，图表的质量往往直接决定了审稿人对论文的第一印象。Reviewers 在评估论文时，"Nice Presentation"（专业排版与高质量图表）是核心评价维度之一。**画一张好图可能需要 1-2 天时间，这是非常正常的投入。**

在开始讲解具体的图表类型之前，先明确几条通用的**绘图铁律**：

| 铁律 | 说明 |
|------|------|
| **必须使用矢量格式** | 导出和插入图表时，必须使用 PDF、EPS 或 SVG 格式，绝对不要使用 PNG 或 JPG 截图插入论文，放大后会模糊，这是典型的"业余"标志 |
| **字体大小要合理** | 图表中的字体（尤其是坐标轴刻度和标签）在插入到期刊/会议排版后，必须与正文字体大小相近（通常不小于 8pt）。千万不要出现图中字小到需要放大镜看的情况 |
| **画布尺寸要小** | 在 Matplotlib 中，将画布设置得小一些（例如 150x100pt），这样字体和线条在缩放后会自然变大、变粗，看起来更清晰。不要用大画布配小字体 |
| **颜色要考虑色盲友好** | 约 8% 的男性有色觉障碍。使用色盲友好的配色方案（如 ColorBrewer），并且永远不要仅依靠颜色来传递信息 |
| **图注（Caption）不可省略** | 每张图都必须有完整的图注，使图表能够独立于正文被理解（Self-contained） |

本节将重点讲解论文中最核心的三类图表。

## 核心目标

Motivated Example Figure 是整篇论文中**最重要的一张图**。它的使命是在读者阅读 Introduction 的前两段后，用一张图在 30 秒内直观地向读者传递两个核心信息：**"这篇论文要解决什么问题"** 以及 **"为什么现有方法/方案不行"**。

这张图通常出现在论文的第一页右上角或第二页顶部，紧跟在 Introduction 中描述 Limitation 的段落之后。它是审稿人决定是否继续认真阅读你论文的"门面"。

## 常见的设计范式

在教育技术论文中，Motivated Example Figure 主要有以下三种经典范式：

### 范式一：Running Example + Failure Case（最推荐）

这是最经典、最有说服力的范式。结合前文提到的 Running Example，给出一个真实的、具体的教学场景，展示现有方案在该场景下的失败。

**案例参考**：假设你研究的是智能导学系统中的个性化推荐问题。你可以在图中展示：一名新生小明的学习画像（入学测验显示其代数薄弱、几何良好），然后并排展示：(a) 现有协同过滤方法的失败——因无历史行为数据而无法推荐，或错误地向已完成微积分学习的学生推荐了基础代数内容；(b) 你提出的知识图谱增强方法的正确推荐路径（基于先验知识给出适合其水平的初始学习序列）。用红色高亮现有方法的失败，用绿色高亮你的方法的正确结果。

### 范式二：Existing vs. Ours 对比图

将图分为左右两栏（或上下两栏）。左边展示现有方案的工作方式及其局限性，右边展示你的方案的工作方式及其优势。通过视觉上的直接对比，让读者一目了然地看到差异。

**案例参考**：教育技术论文中的典型对比——"传统教师主导课堂 vs 人机协同课堂"的信息流转对比图：左边展示传统课堂中教师→学生的单向信息流与反馈滞后（如一周后才拿到作业批改），右边展示人机协同课堂中教师-AI-学生的三角信息流与实时反馈闭环，直观呈现"反馈及时性"这一核心差异。

### 范式三：效果预览图（Performance Teaser）

在 Introduction 中直接放一张精心设计的效果对比图，让读者第一眼就看到你的干预/方法的效果。这种范式适合你的干预在效果上有显著优势的情况。

**案例参考**：教育干预研究中的典型做法——干预组 vs 对照组的效应量对比柱状图：如"采用自适应反馈系统的班级 vs 常规教学班级"在学业成就、学习投入、自我效能三个维度上的效果对比（用效应量与置信区间呈现），直观传达"我们的干预在多个维度上均有显著增益"这一核心卖点。

## 设计原则

- 先在纸上或白板上画草图，与导师讨论确认后再上机绘制，这能避免大量的返工。
- 也可以多参考本教程 Vibe Research 的章节，分享了如何辅助绘图。

## 工具推荐

Motivated Example Figure 通常包含文字、图标、箭头、场景示意图等混合元素，因此推荐使用 **PowerPoint (PPT)** 或 **Figma** 来绘制。PPT 的优势在于上手快、排版灵活，绘制完成后导出为 PDF 即可获得矢量图。Figma 的优势在于协作方便、组件化设计。

插图的 Icon 可以从该网站下载：[iconfont](https://www.iconfont.cn/)、[flaticon](https://www.flaticon.com/)。
