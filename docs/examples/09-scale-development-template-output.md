## Construct Definition

- 构念：学业支持感知公平性 = 学生对预警与支持机制在知情、程序、交互与结果四个层面公平性的感知。
- 锚点：学习分析伦理框架 + 组织公平理论。
- 边界：不包括对教师教学质量的公平性感知；不包括预警模型技术性能。
- 维度（4）：D1 知情透明；D2 程序公正（复核与申诉）；D3 人际尊重；D4 支持充分性。

## Item Pool

- 初始 20 题（每维 5 题），5 点 Likert；正反向题混排避免全部正向作答偏差。
- 专家评审：7 人（2 学习分析伦理、2 学工、1 测量、2 教育技术）；I-CVI 0.71–1.00，修订 4 题、删除 2 题。
- 预测试：n=50 学生；item-total 0.30–0.66；2 题澄清修订。

## Validation Plan

- EFA（n≈300，平行分析定维，斜交旋转）→ CFA（独立样本 n≈300，CFI≥0.90、RMSEA≤0.08 预设）。
- 信度：α 与 McDonald's ω 分维报告；重测（n=40，3 周，ICC）。
- 效度：区分效度（与"总体满意度"单题相关应中等）；效标效度（与申诉率/求助意愿行为指标相关）。
- 测量不变性：按性别与年级检验（ΔCFI≤0.01）。
- 常模/切分点：本阶段不设定；明确需代表性样本 + ROC 证据。

## Remaining Validation Gaps

多校代表性样本、纵向重测、与行为日志的效标关联验证；结果将回接 `mixed-methods-evidence-template` 完成三角互证。
